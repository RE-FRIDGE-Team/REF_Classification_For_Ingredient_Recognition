# 에이전트 오케스트레이션 가이드

> **CLAUDE.md에서 항상 읽지 말 것 — 오케스트레이션 필요 시에만 참조**

## Phase 1에서의 에이전트 전략

Phase 1은 기본적으로 **단일 세션**으로 충분합니다.
아래는 모델 비교 실험 시 병렬 에이전트가 유효한 상황입니다.

### 언제 멀티 에이전트를 쓸 것인가?

| 상황 | 방식 |
|------|------|
| 베이스라인 vs KoELECTRA 동시 학습 | Git worktree + 2 에이전트 |
| 전처리 완료 후 평가 코드 병렬 작성 | 서브에이전트 (Task tool) |
| Phase 2 FAISS 구축 + LLM Fine-tuning 동시 | 멀티 에이전트 필수 |

### Plan Mode 활용 (단일 세션 권장)

```
# 세션 시작 시
"계획만 세워줘, 코드 작성 금지"
→ 계획 검토 후 승인
"이제 구현해줘"
```

### 서브에이전트 호출 예시

```
"다음 두 작업을 독립적으로 실행해줘:
1. src/preprocess.py 작성 (nlp-korean skill 참고)
2. src/evaluate.py 작성 (python-ml skill 참고)
완료되면 두 파일 모두 pytest로 검증해줘"
```

## 에이전트별 컨텍스트 분리 원칙

- 각 에이전트는 **자신의 태스크 파일만** 읽게 할 것
- 모델 체크포인트(수백MB)는 에이전트에 절대 전달 금지
- 결과는 항상 `results/*.json`으로 저장 후 오케스트레이터에 경로만 전달
